## 1. LINE ビジネスアカウント作成

引き継ぎしやすくするため、**個人の LINE アカウントではなく、システム管理用の独立したビジネスアカウント**で作成することを推奨します（Google Sheets 用に独立した Google アカウントを使っているのと同じ考え方です）。

### 1-1. ビジネスアカウントの作成

1. ブラウザで https://account.line.biz/signup にアクセス
2. 「メールアドレスで登録」を選択
3. システム管理用のメールアドレスを入力（個人のものではなく共有メールが望ましい）
4. 届いた認証メールのリンクをクリック
5. 名前・パスワードを設定して登録完了

> **注意**: ビジネスアカウントは個人 LINE アカウントとは独立しています。引き継ぎ時はメールアドレスとパスワードを渡すだけで完了します。

## 2. LINE 公式アカウント作成

### 2-1. LINE Official Account Manager にアクセス

1. ブラウザで https://manager.line.biz/ を開く
2. 手順1で作成したビジネスアカウントでログイン
3. 「アカウントを作成」をクリック

### 2-2. アカウント情報の入力

| 項目 | 設定値の例 |
|------|-----------|
| アカウント名 | `外勤調整システム` |
| メールアドレス | 管理者のメールアドレス |
| 業種（大業種） | `医療・健康` |
| 業種（小業種） | `病院` |

4. 「確認」→「完了」でアカウント作成

### 2-3. プロフィール設定（任意）

- LINE Official Account Manager →「ホーム」→「プロフィール」
- プロフィール画像: システムのアイコン等を設定
- ステータスメッセージ: `外勤スケジュール希望入力` など

## 3. Messaging API 有効化

### 3-1. LINE Official Account Manager から有効化

1. LINE Official Account Manager にログイン
2. 対象アカウントを選択
3. 右上の「設定」をクリック
4. 左メニューの「Messaging API」をクリック
5. 「Messaging APIを利用する」をクリック

### 3-2. プロバイダーの選択・作成

プロバイダーは LINE Developers Console 上でアプリ（チャネル）を管理するための**組織の箱**です。1つのプロバイダーの下に複数のチャネルを持てますが、今回はプロバイダー1つ・チャネル1つで十分です。

- 既存のプロバイダーがあれば選択
- なければ「プロバイダーを作成」をクリック
  - プロバイダー名: `外勤調整` など（ユーザーには見えません）
- 「同意する」→「OK」で有効化完了

> 有効化後、LINE Developers Console にチャネルが自動作成されます。

## 4. チャネル設定（シークレット・トークン取得）

### 4-1. LINE Developers Console にアクセス

1. https://developers.line.biz/console/ にアクセス
2. プロバイダーを選択 → チャネルを選択

### 4-2. チャネルシークレットの取得

1. 「チャネル基本設定」タブを開く
2. 「チャネルシークレット」をコピー → **メモしておく**

### 4-3. チャネルアクセストークンの発行

1. 「Messaging API設定」タブを開く
2. ページ下部の「チャネルアクセストークン（長期）」セクション
3. 「発行」ボタンをクリック
4. 表示されたトークンをコピー → **メモしておく**

> **注意**: チャネルシークレットとアクセストークンは秘密情報です。安全に管理してください。

## 5. GAS にスクリプトを追加

既存の GAS プロジェクト（土曜運用スプレッドシートに設置済み）に、LINE 用のファイルを追加します。

### 5-1. GAS エディタを開く

1. 土曜運用スプレッドシート（外勤調整_土曜外勤）を開く
2. メニュー「拡張機能」→「Apps Script」

### 5-2. 新規ファイルを追加

GAS エディタの左サイドバーで「+」→「スクリプト」で以下の4ファイルを作成し、リポジトリの `gas/` フォルダから内容をコピー＆ペーストしてください:

| 作成するファイル名 | コピー元 | 役割 |
|------------------|---------|------|
| `line_config` | `gas/line_config.gs` | LINE API 設定・共通関数 |
| `line_webhook` | `gas/line_webhook.gs` | Webhook 受信・メッセージ処理 |
| `line_richmenu` | `gas/line_richmenu.gs` | リッチメニュー作成・管理 |
| `line_notify` | `gas/line_notify.gs` | Push 通知（リマインダー・確定通知） |

### 5-3. common.gs の更新

`gas/common.gs` も更新されています。以下の変更点を既存の `common.gs` に反映してください:

1. **`doPost()` 関数**: LINE Webhook の振り分けロジックを追加（`data.events` の有無で判定）
2. **`getDoctorMap()` 関数**: `line_user_id` カラムの読み取りを追加

> **ヒント**: リポジトリの `gas/common.gs` と差分を比較して、変更箇所のみコピーしてください。

## 7. GAS を Web App として再デプロイ

LINE Webhook を受信するため、GAS を Web App として再デプロイします。

### 7-1. デプロイ

1. GAS エディタ右上の「デプロイ」→「デプロイを管理」
2. 既存のデプロイの鉛筆アイコンをクリック
3. 「バージョン」を「新しいバージョン」に変更
4. 「デプロイ」をクリック

> **重要**: 既に Streamlit からの通知用にデプロイ済みの場合は、同じ URL を使い続けるために「デプロイを管理」から更新してください。新規デプロイすると URL が変わり、Streamlit 側の `gas_webapp_url` も更新が必要になります。

### 7-2. Web App URL を確認

- デプロイ完了後に表示される URL をコピー
- 形式: `https://script.google.com/macros/s/XXXX.../exec`

## 9. 応答設定の変更

### 9-1. LINE Official Account Manager で設定

1. https://manager.line.biz/ にログイン
2. 対象アカウントを選択
3. 「設定」→「応答設定」

### 9-2. 以下の設定に変更

| 項目 | 設定値 |
|------|--------|

## 11. リッチメニュー画像の作成

2枚の画像を作成します。サイズは **2500 x 843 ピクセル**（PNG または JPEG）。

### 11-1. 未連携用メニュー画像

```
┌──────────┬──────────┬──────────┬──────────┐
│  連携     │ 希望入力  │ 予定確認  │  ヘルプ   │
│（白背景） │（グレー） │（グレー） │（グレー） │
└──────────┴──────────┴──────────┴──────────┘
```

- 「連携」ボタンは白背景・黒文字（アクティブ）
- 他3つはグレー背景・薄い文字（非アクティブ風）
- ファイル名: `richmenu_unlinked.png`

### 11-2. 連携済み用メニュー画像

```
┌──────────┬──────────┬──────────┬──────────┐
│  連携     │ 希望入力  │ 予定確認  │  ヘルプ   │
│（白背景） │（白背景） │（白背景） │（白背景） │
└──────────┴──────────┴──────────┴──────────┘
```

- 4ボタン全て白背景・黒文字（全てアクティブ）
- ファイル名: `richmenu_linked.png`

### 11-3. 画像を Google Drive にアップロード

1. 作成した2枚の画像を Google Drive にアップロード
2. 各ファイルの**ファイルID**をメモ（URLの `https://drive.google.com/file/d/{ファイルID}/view` の部分）

## 12. リッチメニューの登録

GAS エディタから関数を手動実行します。

### 12-1. リッチメニュー作成

1. GAS エディタで `line_richmenu.gs` を開く
2. 関数選択で `createUnlinkedRichMenu` を選択 → 実行
3. 関数選択で `createLinkedRichMenu` を選択 → 実行

### 12-2. 画像アップロード

1. GAS エディタのコンソール（Ctrl+Enter）で以下を実行:

```javascript
// 未連携用メニューに画像をアップロード
var unlinkedMenuId = PropertiesService.getScriptProperties().getProperty("RICH_MENU_UNLINKED");
uploadRichMenuImage(unlinkedMenuId, "未連携画像のGoogleDriveファイルID");

// 連携済み用メニューに画像をアップロード
var linkedMenuId = PropertiesService.getScriptProperties().getProperty("RICH_MENU_LINKED");
uploadRichMenuImage(linkedMenuId, "連携済画像のGoogleDriveファイルID");
```

### 12-3. デフォルトメニュー設定

1. 関数選択で `setDefaultRichMenu` を選択 → 実行

> これで未連携ユーザーには未連携用メニュー、連携済みユーザーには連携済みメニューが表示されます。

## 13. 動作確認

### 13-1. テスト手順

1. スマートフォンの LINE アプリで公式アカウントを友だち追加
2. ウェルカムメッセージが表示されることを確認
3. リッチメニューの「連携」をタップ
4. Webアプリで表示される6桁の連携コードを入力 → 連携完了メッセージ
5. リッチメニューが連携済み版に切り替わることを確認
6. 「希望入力」→ 月選択 → 各日付の希望入力 → 自由テキスト → 確認 → 登録
7. Google Sheets の `希望_YYYY-MM` シートにデータが保存されていることを確認
8. 「予定確認」→ 確定済みスケジュールが表示されること
9. 「ヘルプ」→ ヘルプメッセージが表示されること

### 13-2. 確認ポイント

- [ ] 友だち追加でウェルカムメッセージ
- [ ] アカウント連携（正常系）
- [ ] アカウント連携（不正なアカウント名）
- [ ] アカウント連携（不正なパスワード）
- [ ] 連携済みで再度「連携」→ 連携済みメッセージ
- [ ] 希望入力の4択（○ / 当直明け○ / △ / ×）
- [ ] 自由テキスト入力（テキスト入力 + 「なし」スキップ）
- [ ] 最終確認表示
- [ ] 「登録する」→ Google Sheets に正しく保存
- [ ] 「やり直す」→ 最初の日付に戻る
- [ ] 受付中の月がない場合のメッセージ
- [ ] リッチメニューの切り替え（未連携→連携済み）

## 14. 管理者の追加・権限譲渡

## 15. 医員への案内

### 案内テンプレート

```
【外勤調整システム LINE 連携のご案内】

外勤スケジュールの希望入力が LINE からできるようになりました。

■ 設定方法
1. 以下のQRコードまたはリンクから公式アカウントを友だち追加
   [QRコード / リンクを貼る]

2. メニューの「連携」ボタンをタップ

3. Webアプリにログインし、アカウント設定の「LINE連携」タブで表示される6桁の連携コードを入力

※従来通りWebアプリからの入力も引き続きご利用いただけます。
```

## 16. トラブルシューティング

### Webhook 検証が失敗する

- GAS が正しくデプロイされているか確認（「デプロイを管理」でステータス確認）
- Webhook URL が正しいか確認（末尾が `/exec` であること）
- GAS のスクリプトにエラーがないか確認（実行ログを確認）

### Bot が応答しない

1. LINE Developers Console で「Webhookの利用」がオンか確認
2. LINE Official Account Manager で「応答メッセージ」がオフか確認
3. GAS の実行ログを確認（「実行」→「実行数」）
4. スクリプトプロパティに `LINE_CHANNEL_ACCESS_TOKEN` が正しく設定されているか確認

### 連携できない（パスワードエラー）

- GAS は **SHA-256 ハッシュ**のみ検証可能です
- bcrypt ハッシュ（`$2b$` で始まる）のパスワードは GAS では検証できません
- 該当の医員は Streamlit 側で一度パスワードをリセットしてください

### リッチメニューが表示されない

1. `setDefaultRichMenu()` が実行済みか確認
2. スクリプトプロパティの `RICH_MENU_UNLINKED` に値があるか確認
3. 画像がアップロードされているか確認（画像なしだとメニューが表示されない）

### 希望が保存されない

1. GAS の実行ログでエラーを確認
2. 運用スプレッドシートに `希望_YYYY-MM` シートが存在するか確認
3. セッションシート（`LINEセッション`）の状態を確認
