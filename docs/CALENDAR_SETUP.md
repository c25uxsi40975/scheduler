# Googleカレンダー連携 セットアップ手順

## 概要

スケジュール確定時に、共有Googleカレンダーに自動で予定（終日イベント）を作成します。
医員はカレンダーを購読（閲覧のみ）して、Googleカレンダーアプリ（PC・スマートフォン）から外勤予定を確認できます。

### 仕組み

```
管理者がスケジュール確定（Streamlit）
  ↓
GAS がメール通知を送信
  ↓（同時に）
GAS が共有カレンダーにイベントを作成
  ↓
医員が Googleカレンダーで予定を確認
```

- カレンダーの予定はシステムが自動管理します（作成・更新・削除）
- 医員が直接カレンダーの予定を編集することはできません（閲覧のみ）
- 再調整やシフト交換が行われると、カレンダーも自動で更新されます

## ステップ1: 共有カレンダーを作成する

GAS を設定した Google アカウントでログインした状態で操作してください。

1. [Googleカレンダー](https://calendar.google.com) を開く
2. 左サイドバーの「他のカレンダー」の右にある **「+」** をクリック
3. **「新しいカレンダーを作成」** を選択
4. カレンダーの名前を入力して「カレンダーを作成」をクリック

### 作成するカレンダー

| カレンダー名（例） | 用途 |
|----------------|------|
| 外勤スケジュール（土曜） | 土曜外勤の全割り当て |
| 外勤スケジュール（○○科） | 平日外勤セクションごと（セクション数分） |

> 名前は自由に設定できます。医員に分かりやすい名前にしてください。

## ステップ2: カレンダーIDを取得する

1. 作成したカレンダーの右にある **「⋮」（三点メニュー）** をクリック
2. **「設定と共有」** を選択
3. 左メニューで対象カレンダー名をクリック
4. 下にスクロールして **「カレンダーの統合」** セクションを表示
5. **「カレンダーID」** をコピーする

カレンダーIDは以下のような形式です:
```
abc123def456@group.calendar.google.com
```

> 注意: メールアドレスのように見えますが、カレンダーの識別子です。

## ステップ3: GASに calendar.gs を追加する

1. GASを設定したスプレッドシート（土曜運用SS）を開く
2. **「拡張機能」→「Apps Script」** をクリック
3. エディタで新しいファイル **「calendar.gs」** を作成
4. `gas/calendar.gs` の内容を貼り付けて **保存**
5. **「デプロイ」→「デプロイを管理」** をクリック
6. 右上の **鉛筆アイコン（編集）** をクリック
7. バージョンを **「新バージョン」** に変更して **「デプロイ」** をクリック

### 権限の承認

初回実行時にカレンダーへのアクセス権限を求められます。

1. Apps Scriptエディタ上部の関数選択で **`testSyncSaturdayCalendar`** を選択
2. **「実行」** をクリック
3. 権限の承認画面が表示されるので許可する
   - 「このアプリは確認されていません」→「詳細」→「移動」
   - 許可する権限: **Googleカレンダーの管理**

## ステップ4: 管理画面でカレンダーIDを登録する

1. Webアプリ（Streamlit）の **管理者画面** → **マスタ管理** タブを開く
2. ページ最下部の **「Googleカレンダー連携設定」** セクションを開く
3. **「カレンダー連携を有効にする」** にチェックを入れる
4. ステップ2で取得した **カレンダーID** を各入力欄に設定:
   - 土曜外勤カレンダーID
   - 平日セクションごとのカレンダーID
5. **「カレンダー設定を保存」** をクリック

## ステップ5: 医員にカレンダーを共有する

医員がGoogleカレンダーで予定を確認できるように、共有設定を行います。

1. [Googleカレンダー](https://calendar.google.com) を開く
2. 共有するカレンダーの **「⋮」→「設定と共有」** を選択
3. **「特定のユーザーとの共有」** セクションまでスクロール
4. **「ユーザーを追加」** をクリック
5. 医員の **Googleメールアドレス** を入力
6. 権限を **「予定の表示（すべての予定の詳細）」** に設定
7. **「送信」** をクリック

> 医員側での操作: 招待メールが届くので「このカレンダーを追加」をクリックすると、自分のGoogleカレンダーに外勤スケジュールが表示されます。

### 複数の医員を一度に追加する場合

手順4〜7を繰り返すか、カンマ区切りで複数のメールアドレスを入力できます。

### 新しい医員が追加された場合

新しい医員がシステムに登録された際は、手動でカレンダーの共有設定にメールアドレスを追加してください。

## 動作確認

1. 管理画面でカレンダー設定が保存されていることを確認
2. テスト用にスケジュールを確定する
3. Googleカレンダーにイベントが作成されていることを確認
4. 医員アカウントでGoogleカレンダーにログインし、共有カレンダーが表示されることを確認

## トラブルシューティング

### カレンダーにイベントが作成されない

1. **カレンダー連携が有効か確認**: 管理画面の「Googleカレンダー連携設定」で有効になっているか
2. **カレンダーIDが正しいか確認**: IDの前後にスペースが入っていないか
3. **GASの実行ログを確認**: Apps Scriptの「実行数」ページでエラーがないか
4. **GASを再デプロイしたか確認**: `calendar.gs` 追加後にWeb Appの再デプロイが必要

### 「カレンダーが見つかりません」エラー

- カレンダーIDが正しいか確認してください
- GASを実行しているGoogleアカウントがカレンダーのオーナーであることを確認してください

### 医員のカレンダーに表示されない

- 共有設定で正しいメールアドレスが追加されているか確認
- 医員が招待メールを承認しているか確認
- 医員のGoogleカレンダーの左サイドバーで「他のカレンダー」に表示されているか確認

### イベントが重複する

通常は発生しません。スケジュール確定時に既存のイベントを自動削除してから再作成します。
万が一重複した場合は、カレンダーIDが途中で変更された可能性があります。古いカレンダーのイベントを手動で削除してください。
