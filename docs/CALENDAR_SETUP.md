# Googleカレンダー連携 セットアップ手順

## 概要

スケジュール確定時に、Googleカレンダーに自動で予定（終日イベント）を作成します。

### 仕組み

```
管理者共有カレンダー（管理者の一覧用）
  ├── 土曜カレンダー（全医員の予定）
  └── 平日セクション別カレンダー（全医員の予定）

医員個別カレンダー（医員ごとに自動作成）
  └── 外勤スケジュール - 山田太郎 ← 土曜+平日の自分の予定のみ
```

- 管理者共有カレンダーには全医員の予定が入ります（管理者の一覧用）
- 医員が連携を有効にすると、**個人用カレンダー**が自動作成されます
- 個人用カレンダーには**自分の予定だけ**が入ります（土曜+平日まとめて）
- 共有招待メール（1通）が届き、承認するとGoogleカレンダーに表示されます
- 再調整やシフト交換が行われると、個人用カレンダーも自動で更新されます

### 医員側の設定

医員がカレンダー連携を利用するには、以下の2つが必要です：

1. **Googleアカウントのメールアドレス**を登録する（Gmail / Google Workspace）
2. **「Googleカレンダー連携を有効にする」**にチェックを入れて保存する

有効にすると個人用カレンダーが作成され、Gmailに共有招待メールが届きます。
無効にすると個人用カレンダーは削除されます。
メール通知とカレンダー連携はそれぞれ独立してON/OFFできます。

## ステップ1: 共有カレンダーを作成する

GAS を設定した Google アカウントでログインした状態で操作してください。

1. [Googleカレンダー](https://calendar.google.com) を開く
2. 左サイドバーの「他のカレンダー」の右にある **「+」** をクリック
3. **「新しいカレンダーを作成」** を選択
4. カレンダーの名前を入力して「カレンダーを作成」をクリック

### 作成するカレンダー

| カレンダー名（例） | 用途 |
|----------------|------|
| 外勤スケジュール（土曜） | 土曜外勤の全割り当て |
| 外勤スケジュール（○○科） | 平日外勤セクションごと（セクション数分） |

> 名前は自由に設定できます。医員に分かりやすい名前にしてください。

## ステップ2: カレンダーIDを取得する

1. 作成したカレンダーの右にある **「⋮」（三点メニュー）** をクリック
2. **「設定と共有」** を選択
3. 左メニューで対象カレンダー名をクリック
4. 下にスクロールして **「カレンダーの統合」** セクションを表示
5. **「カレンダーID」** をコピーする

カレンダーIDは以下のような形式です:
```
abc123def456@group.calendar.google.com
```

> 注意: メールアドレスのように見えますが、カレンダーの識別子です。

## ステップ3: GASに calendar.gs を追加する

### ファイルの追加

1. GASを設定したスプレッドシート（土曜運用SS）を開く
2. **「拡張機能」→「Apps Script」** をクリック
3. エディタで新しいファイル **「calendar.gs」** を作成
4. `gas/calendar.gs` の内容を貼り付けて **保存**

### Calendar Advanced Service の有効化

個人カレンダーへのゲスト追加を招待メールなしで行うため、Google Calendar API の有効化が必要です。

1. Apps Scriptエディタの左サイドバーにある **「サービス」** の横の **「+」** をクリック
2. リストから **「Google Calendar API」** を選択
3. **「追加」** をクリック

### MASTER_SPREADSHEET_ID の設定

`common.gs` の35行目付近にある `MASTER_SPREADSHEET_ID` にマスタ用スプレッドシートのIDを設定してください：

```javascript
var MASTER_SPREADSHEET_ID = "ここにマスタスプレッドシートのIDを貼り付け";
```

スプレッドシートIDは、スプレッドシートのURL `https://docs.google.com/spreadsheets/d/【このID部分】/edit` から取得できます。

### デプロイ

1. **「デプロイ」→「デプロイを管理」** をクリック
2. 右上の **鉛筆アイコン（編集）** をクリック
3. バージョンを **「新バージョン」** に変更して **「デプロイ」** をクリック

### 権限の承認

初回実行時にカレンダーへのアクセス権限を求められます。

1. Apps Scriptエディタ上部の関数選択で **`testSyncSaturdayCalendar`** を選択
2. **「実行」** をクリック
3. 権限の承認画面が表示されるので許可する
   - 「このアプリは確認されていません」→「詳細」→「移動」
   - 許可する権限: **Googleカレンダーの管理**

## ステップ4: 管理画面でカレンダーIDを登録する

1. Webアプリ（Streamlit）の **管理者画面** → **マスタ管理** タブを開く
2. ページ最下部の **「Googleカレンダー連携設定」** セクションを開く
3. ステップ2で取得した **カレンダーID** を各入力欄に設定:
   - 土曜外勤カレンダーID
   - 平日セクションごとのカレンダーID
4. **「カレンダー設定を保存」** をクリック

カレンダーIDを入力して保存すると、カレンダー連携が自動的に有効になります。
IDを空にして保存すると無効になります。

保存時に、既にカレンダー連携を有効にしている医員の個人カレンダーにも
予定が自動で反映されます。

## ステップ5: 医員への案内

医員に以下の手順を案内してください（手動のカレンダー共有設定は不要です）:

1. Webアプリにログインする
2. **「アカウント設定」** → **「メールアドレス設定」** タブを開く
3. **Googleアカウントのメールアドレス**（Gmail または Google Workspace）を登録する
4. **「Googleカレンダー連携を有効にする」** にチェックを入れる
5. **「通知設定を保存」** をクリックする

保存後、確定済みのスケジュールが自動的に医員の個人Googleカレンダーに追加されます。

> メール通知が不要な医員は「メール通知を有効にする」のチェックを外すことで、メール通知のみ停止できます。カレンダー連携とメール通知はそれぞれ独立して設定できます。

## 動作確認

1. 管理画面でカレンダーIDが保存されていることを確認
2. テスト用にスケジュールを確定する
3. 共有カレンダーにイベントが作成されていることを確認
4. テスト医員のカレンダー連携を有効にし、個人カレンダーに予定が表示されることを確認

## トラブルシューティング

### カレンダーにイベントが作成されない

1. **カレンダーIDが正しいか確認**: IDの前後にスペースが入っていないか
2. **GASの実行ログを確認**: Apps Scriptの「実行数」ページでエラーがないか
3. **GASを再デプロイしたか確認**: `calendar.gs` 追加後にWeb Appの再デプロイが必要
4. **MASTER_SPREADSHEET_ID が設定されているか確認**: `common.gs` の変数が空文字のままになっていないか

### 「カレンダーが見つかりません」エラー

- カレンダーIDが正しいか確認してください
- GASを実行しているGoogleアカウントがカレンダーのオーナーであることを確認してください

### 医員の個人カレンダーに予定が表示されない

1. 医員が**Googleアカウントのメールアドレス**を登録しているか確認
2. 医員が**「Googleカレンダー連携を有効にする」**にチェックを入れているか確認
3. 医員が**共有招待メールを承認**しているか確認
4. Google Calendar API (Advanced Service) が有効化されているか確認
5. GASの実行ログで「個別カレンダー作成失敗」エラーがないか確認

### 共有招待メールが届かない

- Google以外のメールアドレス（Yahoo等）では招待メールは届きません
- 迷惑メールフォルダを確認してください
- 医員に Gmail または Google Workspace のメールアドレスを登録してもらってください

### 「個別カレンダー作成失敗」エラー

- GASを実行するGoogleアカウントのセカンダリカレンダー上限（25個）に達している可能性があります
- 不要なカレンダーを削除してから再試行してください

### イベントが重複する

通常は発生しません。スケジュール確定時に既存のイベントを自動削除してから再作成します。
万が一重複した場合は、カレンダーIDが途中で変更された可能性があります。古いカレンダーのイベントを手動で削除してください。
